# 🚚 MetroFlow AI — Smart Urban Logistics & Eco-Routing Engine

> **Theme:** TECH FOR A BETTER TOMORROW  
> **Event:** HACKDAY 1.0  

MetroFlow AI is a dynamic urban freight dispatch and route optimization web application designed to reduce last-mile delivery carbon emissions, bypass peak-hour urban traffic congestion, and support micro-hub transit modal shifts.

---

## 🌟 Key Features

- **Interactive Geospatial Route Map:** Visualizes urban hubs, drop-off locations, and real-time path trajectories using Leaflet.js and OpenStreetMap.
- **Animated Delivery Tracking:** Real-time simulation of electric cargo vans and delivery fleets navigating low-emission delivery corridors.
- **Powertrain-Aware Carbon Engine:** Calculates carbon offset savings (`kg CO₂`) and reduced traffic delays (`mins`) based on vehicle selection (Electric Cargo Vans vs. Cargo E-Bikes vs. Diesel Couriers).
- **Urban Congestion Heatmap Index:** Real-time feedback loops indicating city congestion status and dynamic schedule updates.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern JavaScript (ES6+)
- **Styling:** Tailwind CSS (via CDN) & Custom CSS
- **Mapping Engine:** Leaflet.js & OpenStreetMap
- **Version Control & Hosting:** Git, GitHub, GitHub Pages
